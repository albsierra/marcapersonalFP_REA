Tipado dinámico

No declaras el tipo de una variable:
lo determina el valor que le asignas.

En 2.2 usamos variables de forma intuitiva. Hoy formalizamos las reglas.

Este es el hilo de toda la sección: como el tipo lo pone el valor, una misma variable puede cambiar de tipo, y de ahí saldrá la diferencia entre == y === al final.

Tipos escalares

TipoEjemploSignifica

Tipos compuestos, en el Bloque 3: array y object. Y un tipo especial: null, ausencia de valor.

var_dump()


<?php
  var_dump(2000);     // int(2000)
  var_dump("2000");   // string(4) "2000"
?>

Muestra el tipo y el valor exactos: sirve para distinguir un "2000" (string) de un 2000 (int).

Herramienta de depuración: no la usarás en el HTML final que ve un usuario real.

Los literales 2000 y "2000" son una ilustración añadida a la presentación; en el REA el ejemplo es $horas = 2000; var_dump($horas);. El 4 de string(4) es el número de caracteres de la cadena.

Variables: reglas

  • El nombre empieza por $, seguido de una letra o _
  • Continúa con letras, dígitos o _
  • Distinguen mayúsculas y minúsculas (ya lo vimos en 2.2)

Válidos

$codCiclo

$horas2024

$_temp

No válidos

$2024horas empieza por dígito

$cod-ciclo el guion es una resta

Los ejemplos válidos son los del REA. Los "no válidos" son una ilustración añadida a la presentación.

Una variable puede cambiar de tipo


<?php
  $dato = "DAW";   // ahora mismo es un string
  $dato = 10;      // ahora es un int: no hay ningún error
?>

Cómodo… pero es la causa de bastantes errores sutiles.

Lo veremos enseguida con los operadores de comparación.

Constantes

Un valor con nombre que, a diferencia de una variable, no puede cambiar una vez definido. No lleva $ y, por convención, se escribe en MAYÚSCULAS_CON_GUIONES_BAJOS.

define()

Una función: válida en cualquier punto del script.

const

Una palabra clave: se resuelve al cargar el script.

Para scripts sueltos son equivalentes. En POO (Bloque 3), const también vale dentro de una clase; define(), no.

Constantes en código


<?php
  define('NOMBRE_CENTRO', 'CIFP Carlos III');   // función
  const CODIGO_CENTRO = '30012345';             // palabra clave

  echo '<p>Centro: ', NOMBRE_CENTRO, ' (código ', CODIGO_CENTRO, ')</p>';
?>

Se usan por su nombre, sin $.

Operadores

Combinan uno o varios valores
para producir otro.

  • Aritméticos y de asignación
  • De comparación
  • Lógicos

Aritméticos y de asignación

Aritméticos

+ - * / suma, resta, multiplicación, división

% resto de la división entera (módulo)

De asignación

= asigna

+= -= *= /= .= modifican y reasignan en un paso


$horas += 20;    // equivale a
$horas = $horas + 20;

Operadores de comparación

OperadorCompara
==el valor, convirtiendo tipos si hace falta
===el valor y el tipo, sin convertir nada
!= / !==las versiones negadas de las anteriores
< > <= >=orden

== frente a ===

"10" == 10

true

PHP convierte el string a número antes de comparar.

"10" === 10

false

Los tipos no coinciden: string frente a int.

En este REA usaremos siempre ===: es más predecible y evita errores difíciles de rastrear.

Aquí se cierra el hilo del tipado dinámico: como una variable puede ser "10" o 10 sin que PHP se queje, == puede dar resultados que sorprenden. === no convierte nada. Se dice "salvo que tengamos una razón concreta para lo contrario".

Operadores lógicos

&& y

|| o

! no

Combinan condiciones booleanas. Los usaremos sobre todo a partir del Bloque 3, con las tomas de decisión (if).

Lo esencial

  • PHP tiene tipado dinámico: el tipo lo da el valor, y una variable puede cambiar de tipo
  • var_dump() muestra el tipo y el valor exactos
  • Una constante (define() o const) no cambia y no lleva $
  • Compara con === (valor y tipo), salvo razón concreta

Ejercicio 3 · predice el resultado


<?php
  $horasTotales  = 2000;
  $horasCursadas = 1350;
  echo '<p>Horas restantes: ', $horasTotales - $horasCursadas, '</p>';

  $codCiclo = "10";   // string
  $idCiclo  = 10;     // int

  echo '<pre>';
  var_dump($codCiclo == $idCiclo);    // ¿qué esperas?
  var_dump($codCiclo === $idCiclo);   // ¿y aquí?
  echo '</pre>';
?>

bool(true) y bool(false): == convierte tipos; === no.

Horas restantes: 2000 - 1350 = 650. Conviene que el alumnado anote su predicción ANTES de ejecutar, para que la sorpresa del tipado dinámico se viva en el ejercicio y no solo se lea.
