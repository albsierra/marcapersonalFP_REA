Arrays, en avance

Una variable que contiene
una colección de valores.

Los formalizamos —bucles, arrays multidimensionales, funciones de array…— en el Bloque 3 (CE c). Aquí, solo lo mínimo para guardar y leer datos.

Array indexado

Valores en orden, accesibles por posición (empezando en 0).


<?php
  $ciclos = ['DAW', 'DAM', 'ASIR'];
  echo $ciclos[0];       // DAW
  echo count($ciclos);   // 3
?>

count() devuelve cuántos elementos tiene el array.

Array asociativo

Claves con nombre en vez de posiciones: ideal para agrupar los datos de un mismo currículo.


<?php
  $curriculo = ['alumno' => 'Ana López', 'ciclo' => 'DAW'];
  echo $curriculo['alumno'];   // Ana López
?>

Una lista de currículos

Un array indexado de arrays asociativos: una lista, cada elemento con sus propios campos.


<?php
  $curriculos = [
    ['alumno' => 'Ana López',    'ciclo' => 'DAW',
     'video'  => 'https://youtu.be/curriculo1'],
    ['alumno' => 'Marcos Pérez', 'ciclo' => 'DAM',
     'video'  => 'https://youtu.be/curriculo2'],
    ['alumno' => 'Laura García', 'ciclo' => 'ASIR',
     'video'  => 'https://youtu.be/curriculo3'],
  ];

  echo $curriculos[0]['alumno'];   // Ana López
?>
En el REA cada currículo va en una sola línea; aquí se reparte en dos para que quepa en la diapositiva (mismo array). Los enlaces de vídeo son de ejemplo. El último echo: primero la posición ([0]), luego la clave (['alumno']).

La función mostrarCurriculo()

Con una función —recuerda 2.4— evitamos repetir el mismo echo con distintos campos.


<?php
  function mostrarCurriculo(array $curriculo) {
    echo '<li>', $curriculo['alumno'], ' — ', $curriculo['ciclo'],
         ' — <a href="', $curriculo['video'], '">vídeo</a></li>';
  }
?>

Recibe un currículo (un array asociativo) y emite su <li>.

array $curriculo

Un tipo declarado en un parámetro de función.

  • Sí existe en PHP… a diferencia de las variables sueltas, que no se pueden tipar (2.3)
  • Dice a PHP —y a quien lea la función— que espera recibir un array
  • Si le pasas otra cosa, PHP avisa con un error

Lo retomaremos con más tipos (string, int…) en el Bloque 3.

Montamos la página

Una llamada a la función por cada currículo:


<?php
  echo '<h1>', NOMBRE_CENTRO, ' — Currículos</h1>';
  echo '<ul>';
  mostrarCurriculo($curriculos[0]);
  mostrarCurriculo($curriculos[1]);
  mostrarCurriculo($curriculos[2]);
  echo '</ul>';
?>

NOMBRE_CENTRO es la constante de 2.3 y 2.4, con el valor 'CIFP Carlos III'.

¿Y con 100 currículos?

Con 3, repetir la llamada a mano es asumible.
Con 100, sería absurdo.

Los bucles del Bloque 3 lo resuelven: recorren un array sin repetir el código.

Gancho hacia el Bloque 3. No se enseña foreach aquí: el ejercicio 4 invita, de forma opcional, a que lo investiguen por su cuenta.

Lo esencial

  • Un array guarda varios valores bajo un solo nombre
  • Indexado: por posición · asociativo: por clave con nombre
  • Una función evita repetir la sentencia echo por cada elemento
  • Los parámetros de una función sí pueden llevar tipo declarado
